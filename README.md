# 🎯 ANN Career Prediction Project

## 📌 Overview

This project uses an Artificial Neural Network (ANN) to predict students' future career paths based on their academic performance, skills, and interests.

The model is trained on a dataset of computer science students and performs multi-class classification to identify suitable career options.

---

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

---

## 📊 Dataset

The dataset contains information about students such as:

* Gender
* Age
* GPA
* Major
* Interested Domain
* Projects
* Programming Skills (Python, SQL, Java)

🎯 Target Variable:

* Future Career

---

## ⚙️ Project Workflow

1. Data Loading
2. Data Cleaning
3. Feature Engineering & Encoding
4. Train-Test Split
5. Feature Scaling
6. ANN Model Building
7. Model Training
8. Evaluation using metrics
9. Visualization of results

---

## 🧠 Model Architecture

* Input Layer
* Hidden Layer (ReLU - 16 neurons)
* Hidden Layer (ReLU - 8 neurons)
* Output Layer (Softmax for multi-class classification)

---

## 📈 Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

---

## 📊 Results

The ANN model was successfully trained and evaluated on the dataset.
It achieved reasonable accuracy and demonstrated the ability to classify student career paths effectively.
